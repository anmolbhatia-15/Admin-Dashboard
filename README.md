# Admin Build

A responsive admin dashboard built with React, Vite, and Tailwind CSS — featuring a dashboard overview, product & order management, user management, and a settings panel with a clean, dark sidebar UI.

**Live Demo:** [https://admindashboard.com](https://admindashboard.com) <!-- update with your actual live link -->

---

## Features

- **Dashboard** — Key stats at a glance (Total Users, Active Users, Total Revenue), revenue overview chart, and a recent orders feed
- **Products** — Product table with category, price, stock, and status (In Stock / Low Stock / Out of Stock)
- **Orders** — Order tracking with customer, amount, and status (Completed / Pending / Shipped / Cancelled)
- **Users** — User management with role and active/inactive status
- **Settings** — General settings (site name, theme, language, timezone), notification preferences, and security options like two-factor authentication
- **Profile** — Admin profile page with bio, contact info, and account details
- **Fully Responsive** — Collapsible sidebar and mobile-friendly layouts, tested across breakpoints

## Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Routing:** React Router
- **Deployment:** GitHub Pages

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/anmolbhatia-15/react-admin.git

# Navigate to project folder
cd react-admin

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will run at `http://localhost:5173`

### Build for Production

```bash
npm run build
```
